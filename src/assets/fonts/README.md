# Fonts

Comfortaa and Caveat are loaded via Google Fonts in `src/styles/global.css`.

If the project needs to work offline or self-host fonts, download the WOFF2
files and add `@font-face` declarations here, then update the import in
`global.css` to point to this directory instead of the Google CDN.
